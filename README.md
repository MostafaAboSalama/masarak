
# مسارك | Masarak

**اعرف خطوتك التالية في تعلّم البرمجة والتقنية.**

مسارك موقع عربي يجمع مصادر تعليمية ويرتّبها في خرائط للمسارات الوظيفية والمهارات، ليساعدك على اختيار ما تتعلّمه، وفهم متطلباته، وتطبيقه، ومتابعة تقدّمك.

هذا هو المستودع التعريفي العام للمشروع، ومكان اقتراح التحسينات والإبلاغ عن الأخطاء. كود تطبيق مسارك يُدار بشكل خاص وغير منشور هنا.

## ما الذي يقدّمه مسارك؟

- خرائط لمسارات مثل Frontend وBackend وFull Stack وData Science & AI.
- خرائط مستقلة للمهارات، من CS Fundamentals وPython وJavaScript إلى SQL وReact وASP.NET Core.
- مجموعات وموضوعات مرتّبة، مع توضيح المتطلبات والموضوعات الاختيارية.
- مصادر منظّمة توضّح الفرق بين الشروح البديلة والأجزاء المتتابعة.
- مشروعات وتدريبات مرتبطة بالمهارة المناسبة.
- حفظ تقدّم الزائر في المتصفح، ومزامنة تقدّم الحساب بين الأجهزة عند تسجيل الدخول.
- بحث بالعربية والإنجليزية، مع شرح عربي وأسماء تقنية بالإنجليزية.

المحتوى يُراجع ويتطوّر، وبعض الأقسام ما زال قيد الاستكمال. الدروس والفيديوهات والدورات من إعداد أصحابها؛ مسارك ينظّم روابطها ويحفظ أسماء أصحابها وعناوينها الأصلية. تختلف لغة المصادر وتكلفتها وتوفّرها بحسب المنصة.
